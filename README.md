# MicSoundbar
Desktop-приложение для трансляции MP3-файлов в виртуальный микрофон, позволяющее воспроизводить аудио в голосовых чатах и играх (Discord, Steam Voice Chat, TeamSpeak и др.)

Проект разрабатывается на C/C++ с использованием Qt и Windows API
